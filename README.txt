MRUNAL APKURE PORTFOLIO - VERSION 2

Theme:
Simple, professional, light engineering portfolio with navy accents and minimal animation.

Files:
- index.html
- style.css
- script.js

Important:
The "Download Resume" button currently points to:
Mrunal_Apkure_Resume.pdf

To make it work:
1. Put your PDF resume in this folder.
2. Rename it exactly to: Mrunal_Apkure_Resume.pdf

To add your photo:
Replace the photo-placeholder block in index.html with:
<img src="profile.jpg" alt="Mrunal Apkure" class="profile-photo">

Then add your image file as profile.jpg and this CSS:
.profile-photo{width:100%;height:220px;object-fit:cover;border-radius:12px;border:1px solid #dfe4ea}

To publish:
Upload all files to GitHub and enable GitHub Pages.
