BEST GITHUB PAGES SETUP
1. Sign in to GitHub.
2. Create a NEW PUBLIC repository named exactly:
   mrunalapkure.github.io
3. Upload ALL files from this folder directly into that repository.
4. Open repository Settings > Pages.
5. Under Build and deployment, select:
   Deploy from a branch
6. Choose:
   Branch: main
   Folder: / (root)
7. Save.
8. Wait a few minutes, then open:
   https://mrunalapkure.github.io/

GOOGLE SEARCH CONSOLE
1. Open Google Search Console.
2. Add this property:
   https://mrunalapkure.github.io/
3. Verify ownership using the method Google provides.
4. Use URL Inspection and enter:
   https://mrunalapkure.github.io/
5. Click Request Indexing.
6. Submit this sitemap:
   https://mrunalapkure.github.io/sitemap.xml
