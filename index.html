01 · Final Year Project

FPGA Implementation of I-CDPK Codec

Final-year project focused on FPGA-oriented implementation of Interleaved Chaotic Differential Peaks Keying (I-CDPK) for baseband digital communication.

  • Modelled Lorenz chaotic X, Y and Z signals using MATLAB/Python.
  • Worked on peak detection and differential peak processing.
  • Performed 32-bit signed Q10.21 fixed-point analysis.
  • Implemented Verilog HDL modules in Xilinx Vivado.
  • Verified modules using XSim behavioral simulation.
  • Completed synthesis, implementation and timing verification for an Artix-7 target.
